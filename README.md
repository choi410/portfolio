# 로봇 자동화 프로젝트 모음

자율주행 이동로봇, PLC 공정 제어, 산업용 로봇 시뮬레이션, 차량 CAN 통신, IoT 센서 모니터링 프로젝트의 소스 코드입니다.

| 폴더 | 프로젝트 | 기술 |
|---|---|---|
| [beagle-autonomous-driving](beagle-autonomous-driving) | LiDAR·Vision 센서 융합 자율주행 비글 (혁신아카데미 로봇분야 대상) | Python, 360° LiDAR, OpenCV, P 제어 |
| [plc-stacker-crane](plc-stacker-crane) | PLC 기반 색상 인식 스태커 크레인 자동 적재 시스템 | LS XG5000, Ladder, Factory I/O, Modbus TCP |
| [robodk-pick-and-place](robodk-pick-and-place) | RoboDK·Python 자동 조립·적재 공정 | RoboDK API, Python, 좌표 변환 |
| [canoe-capl-vehicle](canoe-capl-vehicle) | CANoe·CAPL 차량 제어 시스템 | CANoe, CAPL, CANdb++ (DBC) |
| [tomato-monitoring](tomato-monitoring) | 라즈베리파이 기반 토마토 생육 환경 모니터링 | Raspberry Pi, Python, Flask, GPIO·I2C·UART |
